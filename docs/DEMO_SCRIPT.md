# 3-minute demo script

1. **Problem (20s):** "Creators juggle YouTube, Instagram and Facebook dashboards and still don't know *why* something worked."
2. **Leaderboard (40s):** Show the ranking. Flip platform tabs, switch 24h / 7d / 30d, switch Views -> Follower gain. Point at the rank-change arrows.
3. **Add accounts (20s):** "+ Add account", pick Instagram, type any handle. It joins the ranking. Multiple accounts per platform work.
4. **AI strategy (60s):** Click an account. Show the audience breakdown (age, gender, country), then "Generate strategy": audience profile, inferred interests, what to create next, conclusion. Open "Top posts" -> "Why did this work?" for hook/pacing/thumbnail analysis.
5. **Idea generator (20s):** Top bar -> Idea generator: hooks and 3-point outlines from your own top history.
6. **Open source + real APIs (20s):** Gemma (open weights) via the Gemini API, FastAPI, MIT license, Dockerfile for DigitalOcean. Real data path: YouTube Data/Analytics API, Instagram Graph API, Facebook Graph API (demographics need owner OAuth; interests are AI-inferred).
